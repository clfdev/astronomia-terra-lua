Possíveis causas do problema
1. Arquivos desatualizados na pasta www
O Capacitor/Android só copia o que está em www. Se você edita/atualiza a página na raiz do projeto mas não copia manualmente para www, pode estar indo uma versão antiga ou diferente para o APK.

2. Arquivos duplicados ou conflitantes
Se há múltiplas versões de arquivos (por exemplo, visual-fases-lua.html na raiz e em www), o APK só vai usar a de www. Se o conteúdo diverge, o APK não reflete o que você vê na web.

3. Problemas de cache ou build antigo
O Android Studio pode estar usando arquivos antigos por cache, ou o Gradle não está limpando corretamente entre builds.

4. Problemas de encoding ou path
Arquivos copiados com encoding diferente, nomes de arquivos com acentos ou maiúsculas/minúsculas diferentes podem causar problemas no Android.

5. Mistura de assets entre idiomas
Se o script dinâmico de idioma está mal configurado no APK (por path, por exemplo), pode carregar o texto em português na página em inglês.

Limpe o build do Android Studio
